Bibliografía

BibTeX, citas automáticas y organización de papers — el gestor bibliográfico que todo investigador termina necesitando

// ZoteroBibTeXBibliografíaPapersarXiv

Gestionar referencias bibliográficas manualmente es una de las tareas más frustrantes de la escritura científica. Copiar datos de papers a mano, mantener un archivo .bib actualizado, verificar que el formato sea exactamente el que pide el journal, asegurarse de que cada cita en el texto tenga su entrada en la bibliografía y viceversa: todo eso es propenso a errores y consume tiempo que debería estar dedicado a la física. Zotero automatiza todo este proceso.

Zotero es un gestor de referencias bibliográficas gratuito y de código abierto. Permite guardar papers, libros y recursos web en una biblioteca organizada, importarlos directamente desde el navegador (con un clic en una página de arXiv, Physical Review o Google Scholar), y exportar la bibliografía en formato BibTeX para usar con LaTeX. Con el plugin para Word también funciona fuera de LaTeX, pero para un físico la integración BibTeX es la clave.

¿Para qué sirve en física?

Cualquier documento que requiera citas bibliográficas —un informe de laboratorio con antecedentes, un trabajo práctico, la introducción de una tesis, un paper— se beneficia de Zotero. Permite capturar la referencia completa de un paper en arXiv o Physical Review con un clic (título, autores, DOI, abstract, año, journal), organizar los papers por tema o proyecto, y exportar la bibliografía como archivo .bib listo para usar en LaTeX. Cuando el mismo paper aparece en 15 documentos distintos, Zotero lo gestiona una vez y lo reutiliza en todos.

Flujo de trabajo típico con Zotero + LaTeX: 1. Encontrás un paper relevante en arXiv o APS 2. Hacés click en el conector de Zotero en el navegador 3. Zotero importa automáticamente todos los metadatos 4. Exportás tu biblioteca (o colección) como .bib 5. En LaTeX: \bibliography{mi_biblioteca} 6. Cada \cite{Dirac1928} se formatea automáticamente

Instalación

# 1. Descargar Zotero desde https://www.zotero.org/download/ # (disponible para Windows, macOS y Linux) # 2. Instalar el conector del navegador (Zotero Connector) # Chrome: https://chrome.google.com/webstore/ # Firefox: https://addons.mozilla.org/ # El conector detecta automáticamente papers en: # arXiv, APS, AIP, Elsevier, Springer, Google Scholar... # 3. (Opcional) Crear cuenta en zotero.org para sincronización # La nube gratuita incluye 300 MB para PDFs # No requiere configuración adicional para uso básico # Para LaTeX: File → Export Library → BibTeX (.bib)

Ejemplo de uso: from arXiv to BibTeX

El flujo completo desde encontrar un paper hasta citarlo en LaTeX, sin escribir una sola línea de BibTeX manualmente:

% PASO 1: En el navegador, vas a % https://arxiv.org/abs/1905.09272 (por ejemplo) % Hacés click en el ícono de Zotero en la barra del navegador % Zotero importa automáticamente: título, autores, año, DOI, abstract % PASO 2: En Zotero, click derecho en la colección → Export Collection % Formato: BibTeX → guardar como "referencias.bib" % Lo que Zotero genera automáticamente: @article{Maas2019, title = {The Gribov problem and QCD dynamics}, author = {Maas, Axel}, journal = {Physics Reports}, volume = {524}, number = {4}, pages = {203--300}, year = {2019}, doi = {10.1016/j.physrep.2012.11.002} } % PASO 3: En tu documento LaTeX \usepackage[backend=bibtex, style=unsrt]{biblatex} \addbibresource{referencias.bib} % En el texto: La cromodinámica cuántica presenta el problema de Gribov en el gauge de Landau \cite{Maas2019}. % Al compilar, LaTeX formatea automáticamente la cita y % genera la sección de bibliografía con el estilo correcto

BibTeX vs BibLaTeX: BibTeX es el sistema clásico y es suficiente para la mayoría de los documentos. BibLaTeX es el sucesor moderno con más opciones de formato y mejor manejo de caracteres Unicode. Para física, el estilo unsrt (referencias en orden de aparición) es el más común. Physical Review usa su propio estilo: apsrev4-2.bst, incluido en la plantilla oficial de APS para Overleaf.

Zotero + arXiv: captura perfecta

arXiv es el repositorio donde se publica prácticamente toda la física moderna antes de la revisión formal. El conector de Zotero reconoce las páginas de arXiv automáticamente: al visitar arxiv.org/abs/xxxx.xxxxx aparece el ícono de Zotero en el navegador listo para importar. También descarga automáticamente el PDF del paper y lo adjunta a la referencia en tu biblioteca. Toda la física que leés, organizada en un clic.

Zotero es la diferencia entre tener una "lista de papers que leí" y tener una biblioteca científica organizada y utilizable. Una vez que tenés cientos de referencias acumuladas a lo largo de la carrera, la diferencia entre encontrar lo que necesitás en 10 segundos o en 20 minutos es exactamente Zotero. Para la tesis, donde la bibliografía puede tener 100 o 200 entradas, no tenerlo no es una opción real.
