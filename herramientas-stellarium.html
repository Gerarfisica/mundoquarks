🌌 Stellarium:
El Planetario
en tu Computadora

El cielo completo renderizado en tiempo real — cualquier lugar, cualquier fecha, cualquier hora desde el año −100.000 hasta el año 100.000

// StellariumAstronomíaPlanetarioAstrofísicaDocencia

Stellarium es un planetario de código abierto que renderiza el cielo en tiempo real con una precisión astronómica notable. Muestra estrellas, planetas, constelaciones, nebulosas, cúmulos, galaxias, la Vía Láctea, cometas, asteroides, satélites artificiales y fenómenos como eclipses y ocultaciones — todo en una proyección esférica que imita exactamente lo que se vería a simple vista, con binoculares o con un telescopio desde cualquier punto del planeta Tierra, para cualquier fecha y hora.

No es solo un programa bonito: Stellarium usa efemérides astronómicas reales (VSOP87 para planetas, algoritmos de precesión IAU) y un catálogo de más de 600.000 estrellas en su versión estándar — ampliable a más de 200 millones con catálogos adicionales. La precisión posicional es suficiente para planificar observaciones reales, predecir conjunciones y eclipses, y verificar lo que se va a ver en el telescopio antes de salir al campo.

¿Para qué sirve en física?

Para un físico o estudiante de física, Stellarium tiene valor en varios contextos. En astronomía y astrofísica, permite visualizar conceptos abstractos: la esfera celeste, la eclíptica, la precesión de los equinoccios, el movimiento retrógrado de los planetas, las fases de la Luna. En docencia, reemplaza al planetario físico para mostrar el cielo nocturno en un aula sin importar si hay luz solar. Para observaciones reales, permite planificar qué objetos estarán visibles, a qué hora salen y se ponen, y en qué parte del cielo buscarlos.

Objetos y fenómenos que Stellarium simula: · 600.000+ estrellas (ampliable a 200 millones) · 8 planetas + Plutón, lunas, asteroides, cometas · Catálogo Messier completo (nebulosas, cúmulos, galaxias) · Catálogo NGC/IC · Satélites artificiales en tiempo real (ISS, Hubble, etc.) · Eclipses solares y lunares · Conjunciones y ocultaciones planetarias · Lluvia de meteoros (Perseidas, Leónidas, etc.) · Movimiento de la Vía Láctea

Instalación

# Descarga oficial desde https://stellarium.org/ # Disponible para Windows, macOS y Linux # Linux (Ubuntu/Debian) sudo apt install stellarium # O descarga el .deb/.AppImage desde el sitio oficial # macOS # Descargar el .dmg desde stellarium.org # O via Homebrew: brew install --cask stellarium # También disponible como app web SIN instalación: # https://stellarium-web.org # (versión reducida, ideal para mostrar en clase desde el navegador)

Configurar la ubicación: Lo primero al abrir Stellarium es configurar la ubicación geográfica. Para Buenos Aires: F6 → Search → "Buenos Aires" o ingresar manualmente las coordenadas (34°36'S, 58°22'O). Esto es crucial porque el cielo visible desde el hemisferio sur es completamente diferente al del norte — las constelaciones circumpolares, la orientación de la Vía Láctea y la posición de los planetas cambian completamente.

Guía de uso esencial

Atajos de teclado fundamentales: F1 → Ayuda F2 → Configuración (calidad, atmósfera, etc.) F3 → Buscar objeto (escribir nombre: "Jupiter", "M31", "Orion") F6 → Configurar ubicación geográfica F5 → Configurar fecha y hora Espacio → Centrar en el objeto seleccionado / → Zoom in \ → Zoom out L / J → Avanzar / retroceder en el tiempo K → Volver a tiempo real A → Mostrar/ocultar atmósfera (ver estrellas de día) G → Mostrar/ocultar suelo C → Mostrar/ocultar constelaciones H → Mostrar/ocultar líneas del horizonte Flujo de trabajo para planificar una observación: 1. F6 → configurar ubicación (Buenos Aires) 2. F5 → configurar la fecha y hora de la observación 3. F3 → buscar el objeto que querés observar 4. Verificar altitud sobre el horizonte (>20° recomendado) 5. Notar la hora de salida y puesta del objeto 6. Identificar estrellas de referencia cercanas para encontrarlo

Stellarium en el aula del profesorado: Para enseñar astronomía en el profesorado o en la secundaria, Stellarium resuelve el problema más concreto: explicar fases de la Luna, eclipses o movimiento planetario sin poder mostrar el cielo real. Con Stellarium en el proyector, podés avanzar el tiempo para mostrar cómo se mueve el Sol en el horizonte a lo largo del año, recrear el eclipse que ocurrió en tal fecha, o mostrar por qué Venus siempre aparece cerca del horizonte al amanecer o al atardecer. El tiempo acelerado es la función más poderosa para docencia.

Catálogos adicionales y extensiones

Stellarium permite ampliar su catálogo de estrellas desde la versión estándar (600K estrellas) hasta más de 200 millones instalando catálogos adicionales desde la configuración. Para uso docente o amateur, el catálogo estándar es más que suficiente. Para uso astronómico más serio, los catálogos extendidos (Tycho-2, USNO) permiten encontrar objetos débiles y planificar observaciones con telescopios grandes.

Stellarium Web: sin instalación desde el navegador

La versión web stellarium-web.org corre directamente en el navegador sin instalar nada. Es una versión algo reducida (menos objetos, sin catálogos extendidos) pero completamente funcional para uso docente y exploración casual. Ideal para mostrar en clase desde cualquier computadora sin necesidad de instalar el programa. También hay apps móviles oficiales para Android e iOS.

Stellarium para docentes — uso en el aula
Cómo usar Stellarium como herramienta pedagógica: eclipses, fases lunares y movimiento planetario.

Stellarium hace algo que ningún libro de astronomía puede hacer: mostrar el cielo moviéndose. No como una foto sino como un proceso vivo — los planetas desplazándose sobre la eclíptica, la Luna cambiando de fase, el Sol describiendo su arco estacional en el horizonte. Para un estudiante de física que nunca pudo salir a observar el cielo, Stellarium es la puerta de entrada a la astronomía observacional. Para el docente, es el planetario que no existe en la mayoría de las escuelas argentinas, disponible gratis en cualquier computadora.
