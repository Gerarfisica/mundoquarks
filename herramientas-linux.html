Bash · Terminal

El sistema operativo de la ciencia — clústeres de cómputo, scripts, SSH y el poder de la línea de comandos

Los supercomputadores del mundo corren Linux. Los servidores del CERN corren Linux. Los clústeres de cómputo de las universidades corren Linux. Si alguna vez necesitás correr una simulación seria, procesar terabytes de datos experimentales o conectarte remotamente a un servidor de tu institución, vas a encontrar Linux del otro lado. No es una coincidencia: Linux es el sistema operativo que los físicos y científicos eligieron colectivamente porque da control total sobre el entorno, es gratuito, abierto y extremadamente estable para tareas de largo aliento.

Para un físico, lo más valioso de Linux no es la interfaz gráfica sino la terminal y el lenguaje Bash. La terminal permite automatizar tareas repetitivas (procesar cientos de archivos de datos con un loop de una línea), gestionar recursos del sistema, conectarse a servidores remotos y encadenar herramientas en pipelines de análisis. Una vez que dominás la terminal, muchas tareas que llevarían horas manualmente se reducen a segundos.

¿Para qué sirve en física?

En el trabajo diario de laboratorio y en física computacional, Linux y Bash son el pegamento que conecta todas las demás herramientas. Python, LaTeX, Git, Gnuplot y la mayoría de los programas de análisis científico funcionan nativamente en Linux. Además, los clústeres de cómputo de alta performance (HPC) donde se corren simulaciones grandes son invariablemente Linux, y la única forma de usarlos es por SSH desde la terminal.

Usos típicos en física: · Procesar en batch cientos de archivos de datos · Automatizar compilación y ejecución de simulaciones · Conectarse por SSH a clústeres HPC remotos · Scripts Bash para pipeline de análisis (datos → gráficos) · Administración de entornos Python (conda, pip) · Programar tareas con cron (ejecución automática periódica) · Transferir datos masivos con rsync/scp

Instalación

Hay tres formas de tener Linux sin abandonar tu sistema actual. La más recomendada para estudiantes que usan Windows es WSL2 (Windows Subsystem for Linux), que instala un Ubuntu completo dentro de Windows sin necesidad de reparticionado. En macOS, la terminal ya usa un sistema Unix-like compatible con la mayoría de los comandos Linux. La opción más completa es instalar Linux como sistema principal o en dual-boot.

# --- Windows: instalar WSL2 (Ubuntu en Windows) --- # Abrir PowerShell como administrador: wsl --install # Reiniciar y completar la configuración de Ubuntu # --- Ubuntu / Debian (ya tenés Linux) --- sudo apt update && sudo apt upgrade # mantener el sistema actualizado # --- macOS --- # La Terminal de macOS ya es Unix-like # Para instalar herramientas GNU adicionales: brew install coreutils # Verificar que tenés Bash bash --version echo $SHELL # ver qué shell estás usando

Ejemplo de uso: automatización con Bash

Supongamos que tenés 50 archivos de datos de laboratorio con el formato medicion_01.csv hasta medicion_50.csv y querés correr tu script de análisis en cada uno y guardar los resultados. En Windows haría esto manualmente. En Bash:

#!/bin/bash # Script: procesar_datos.sh # Procesa todos los archivos CSV de mediciones # --- Comandos básicos de navegación --- pwd # mostrar directorio actual ls -la # listar archivos con detalles cd datos/ # entrar a directorio mkdir resultados # crear directorio # --- Procesar múltiples archivos en loop --- for archivo in medicion_*.csv; do nombre="${archivo%.csv}" # quitar extensión echo "Procesando: $archivo" python analisis.py "$archivo" --output "resultados/${nombre}_resultado.csv" done echo "Listo. $(ls resultados/ | wc -l) archivos procesados." # --- Buscar archivos --- find . -name "*.csv" -newer referencia.csv # archivos CSV más nuevos que referencia grep -r "ERROR" logs/ # buscar "ERROR" en todos los logs # --- Transferir datos a/desde servidor remoto --- scp datos/*.csv usuario@cluster.uba.ar:~/experimento/ ssh usuario@cluster.uba.ar # conectarse al servidor # --- Monitorear recursos del sistema --- htop # monitor de procesos interactivo df -h # espacio en disco free -h # memoria RAM disponible

El pipe |: El operador pipe es uno de los conceptos más poderosos de Unix. Conecta la salida de un comando con la entrada del siguiente, permitiendo construir pipelines complejos. Por ejemplo, cat datos.csv | grep "2024" | sort | uniq -c lee el archivo, filtra las líneas con "2024", las ordena y cuenta cuántas veces aparece cada valor único. Todo en una línea, sin archivos intermedios. Es la filosofía Unix: herramientas pequeñas que hacen una sola cosa bien, combinadas para resolver problemas complejos.

SSH y los clústeres HPC de universidades argentinas

La UBA (a través de FCEN-UBA) y el CONICET tienen acceso a clústeres de cómputo de alta performance. El acceso es siempre por SSH: ssh usuario@cluster.institución.ar. Una vez adentro, el trabajo se hace completamente desde la terminal. Las simulaciones se envían como jobs al gestor de colas (SLURM o PBS), que las distribuye automáticamente entre los nodos disponibles. Sin Linux y Bash no hay forma de usar estos recursos.
