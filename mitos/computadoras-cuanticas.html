Las computadoras cuánticas no reemplazarán tu PC

Por qué la computación cuántica no es "más rápida en general" sino útil solo para problemas específicos

// El mito

Las computadoras cuánticas son simplemente computadoras clásicas pero mucho más rápidas. Pronto reemplazarán a todos los ordenadores actuales y resolverán cualquier problema instantáneamente.

// La realidad

Las computadoras cuánticas no son más rápidas "en general". Para la mayoría de las tareas cotidianas (navegar internet, editar texto, ver videos), una computadora cuántica no ofrece ninguna ventaja sobre una clásica. Son drásticamente más eficientes solo para ciertos problemas matemáticos específicos donde existen algoritmos cuánticos especializados.

Cómo Funciona La Computación Cuántica

Una computadora clásica procesa bits (0 o 1). Una cuántica usa qubits, que pueden estar en superposición de 0 y 1. Con N qubits, el sistema puede estar en superposición de 2^N estados simultáneamente. El algoritmo cuántico manipula esa superposición usando interferencia para amplificar las respuestas correctas y cancelar las incorrectas. Al final, la medición colapsa el sistema a la respuesta.

La ventaja no viene de "probar todas las respuestas en paralelo" (ese es el mito). Viene de explotar la interferencia cuántica para que ciertos cálculos converjan más rápidamente. Esto solo funciona si el problema tiene la estructura matemática específica que el algoritmo cuántico puede explotar.

Los Algoritmos Cuánticos Conocidos

Algoritmo de Shor (1994): factoriza números enteros enormes en tiempo polinomial (exponencialmente más rápido que los mejores algoritmos clásicos conocidos). Rompería la mayoría de los sistemas de criptografía actuales (RSA). Por eso los gobiernos y empresas están desarrollando criptografía post-cuántica.

Algoritmo de Grover (1996): busca en una base de datos no ordenada en O(√N) en vez de O(N). Una aceleración cuadrática, no exponencial.

Simulación cuántica: modelar sistemas cuánticos complejos (moléculas para diseño de fármacos, materiales superconductores) que son exponencialmente difíciles para computadoras clásicas.

Lo que NO hace más rápidoLas computadoras cuánticas no tienen ventaja demostrada sobre las clásicas para: navegación web, procesamiento de texto o imágenes, reproducción de video, videojuegos, bases de datos relacionales, inteligencia artificial general, o la mayoría de los problemas de ingeniería cotidianos. Para estas tareas, tu laptop seguirá siendo mejor durante décadas, si no siempre.

El Estado Actual De La Tecnología

Los mejores procesadores cuánticos actuales (2024) tienen del orden de 1000-2000 qubits físicos, pero con tasas de error tan altas que los qubits "lógicos" (con corrección de errores) son mucho menos. Para implementar el algoritmo de Shor y romper el cifrado RSA-2048 se necesitarían millones de qubits físicos de alta calidad. Eso está a décadas de distancia, si es que alguna vez es alcanzable.
