NumPy, SciPy, Matplotlib, Pandas, Jupyter — el ecosistema que reemplazó a MATLAB en los laboratorios del mundo

// PythonNumPySciPyMatplotlibJupyter

Si en los años 90 un físico quería analizar datos, necesitaba MATLAB o Fortran. Hoy, Python es el lenguaje dominante en física computacional, astronomía, física de partículas y prácticamente todas las ramas experimentales de la ciencia. No porque sea el más rápido ni el más elegante en términos formales, sino porque su ecosistema científico —construido por la comunidad durante dos décadas— es sencillamente insuperable. Desde el análisis de datos del LHC hasta el procesamiento de imágenes del telescopio James Webb, Python está detrás.

Lo que hace especial a Python en física no es el lenguaje base, sino las bibliotecas que lo rodean: NumPy para álgebra lineal y arrays de alta performance, SciPy para métodos numéricos, integración y optimización, Matplotlib para graficación publicable, y Jupyter para el flujo de trabajo interactivo que mezcla código, ecuaciones y texto en un mismo documento. Esta combinación convierte a Python en un entorno completo para el trabajo científico moderno.

¿Para qué sirve en física?

Python cubre prácticamente todo el flujo de trabajo experimental y teórico. En el laboratorio, se usa para adquirir datos de instrumentos (osciloscopios, multímetros, sensores) via GPIB, USB o puertos seriales. Una vez obtenidos los datos, permite limpiarlos, ajustar curvas con mínimos cuadrados, calcular incertezas y graficar resultados con calidad de publicación. En física teórica y computacional, permite resolver EDOs, EDPs, sistemas de ecuaciones y problemas de autovalores que aparecen en mecánica cuántica, electrodinámica y mecánica estadística.

Usos típicos en física experimental: · Ajuste de curvas: scipy.optimize.curve_fit · Transformada de Fourier: numpy.fft · Integración numérica: scipy.integrate.odeint / solve_ivp · Álgebra lineal: numpy.linalg (autovalores, SVD, inversas) · Estadística: scipy.stats (distribuciones, tests, regresión) · Visualización: matplotlib, seaborn, plotly

En simulación, Python permite implementar métodos de Runge-Kutta para integración de ecuaciones de movimiento, resolver la ecuación de Schrödinger numéricamente, simular cadenas de Markov para mecánica estadística o modelar flujos con diferencias finitas. Para análisis de señales experimentales —como los que aparecen en laboratorios de acústica, óptica o electrónica— la combinación NumPy + SciPy es directamente equivalente a lo que hacía MATLAB, pero gratuita y con código reproducible.

Instalación

La forma recomendada para trabajo científico es instalar Anaconda o su versión liviana Miniconda. Anaconda viene con NumPy, SciPy, Matplotlib, Pandas y Jupyter preinstalados, lo que evita problemas de dependencias. Alternativamente, se puede usar la instalación estándar de Python con pip.

# Opción 1: Anaconda (recomendado para ciencia) # Descargar desde https://www.anaconda.com/download # Luego en terminal: conda create -n fisica python=3.11 conda activate fisica conda install numpy scipy matplotlib jupyter pandas # Opción 2: Python + pip estándar pip install numpy scipy matplotlib jupyter pandas # Verificar instalación python -c "import numpy; print(numpy.__version__)"

Para trabajo diario, Jupyter Lab es el entorno más cómodo: permite combinar celdas de código Python con texto en Markdown, fórmulas LaTeX y gráficos, todo en el navegador. Es el formato estándar de notebooks científicos y se usa en cursos del MIT, CERN y prácticamente todas las universidades del mundo.

Ejemplo de uso: ajuste de curvas experimentales

Uno de los usos más frecuentes en física experimental es ajustar un modelo teórico a datos medidos, obteniendo los parámetros del modelo y sus incertezas. El siguiente ejemplo muestra cómo ajustar una curva de resonancia (Lorentziana) a datos experimentales, típico en óptica, electrónica o mecánica:

import numpy as np import matplotlib.pyplot as plt from scipy.optimize import curve_fit # Modelo: Lorentziana (curva de resonancia) def lorentziana(f, f0, gamma, A): return A / (1 + ((f - f0) / (gamma/2))**2) # Datos experimentales (frecuencia en Hz, amplitud en V) frecuencia = np.array([95, 97, 99, 100, 101, 103, 105]) amplitud = np.array([0.12, 0.31, 0.78, 1.02, 0.75, 0.28, 0.11]) incerteza = np.array([0.02, 0.03, 0.04, 0.05, 0.04, 0.03, 0.02]) # Ajuste con mínimos cuadrados ponderados p0 = [100, 4, 1.0] # valores iniciales: [f0, gamma, A] popt, pcov = curve_fit(lorentziana, frecuencia, amplitud, p0=p0, sigma=incerteza) perr = np.sqrt(np.diag(pcov)) # incertezas de los parámetros print(f"f0 = {popt[0]:.2f} ± {perr[0]:.2f} Hz") print(f"gamma = {popt[1]:.2f} ± {perr[1]:.2f} Hz") print(f"Factor de calidad Q = {popt[0]/popt[1]:.1f}") # Gráfico con barras de error y curva ajustada f_fino = np.linspace(93, 107, 300) plt.figure(figsize=(8, 5)) plt.errorbar(frecuencia, amplitud, yerr=incerteza, fmt='o', color='#00d4ff', label='Datos') plt.plot(f_fino, lorentziana(f_fino, *popt), color='#f5a623', label=f'Ajuste: f₀={popt[0]:.1f} Hz') plt.xlabel('Frecuencia (Hz)') plt.ylabel('Amplitud (V)') plt.legend() plt.tight_layout() plt.savefig('resonancia.pdf', dpi=150) plt.show()

scipy.optimize.curve_fit usa el algoritmo de Levenberg-Marquardt para minimizar la suma de residuos al cuadrado. Cuando se pasa el parámetro sigma con las incertezas experimentales, el ajuste es ponderado: los puntos con menor incerteza tienen mayor peso. La matriz de covarianza pcov devuelta contiene las varianzas de los parámetros en la diagonal, de las cuales se extraen las incertezas con la raíz cuadrada. Este es el flujo estándar para reportar ajustes en informes de laboratorio.

Python en física de partículas: ROOT y uproot

El CERN desarrolló históricamente el framework ROOT (en C++) para análisis de datos de alta energía. Hoy existe uproot, una biblioteca Python que permite leer archivos ROOT directamente, integrando el ecosistema del CERN con NumPy/Pandas. Si en algún momento trabajás con datos abiertos del LHC, uproot es la puerta de entrada.

Python no es solo una herramienta de programación: es el lenguaje común de la física moderna. Aprender su ecosistema científico es tan fundamental hoy como saber usar un osciloscopio o escribir en LaTeX. La curva de aprendizaje inicial es baja, el techo es altísimo, y la comunidad que lo rodea —desde Stack Overflow hasta los foros del CERN— es inmensa. Si estás en física y todavía no lo usás sistemáticamente, este es el momento.
