// 01¿Qué es Python?

Python es un lenguaje de programación de propósito general creado por Guido van Rossum en 1991. Su diseño prioriza la legibilidad: el código Python se parece más al pseudocódigo matemático que al ensamblador, lo que lo hace ideal para científicos que quieren enfocarse en la física, no en la sintaxis.

En las últimas dos décadas, la comunidad científica construyó alrededor de Python un ecosistema de librerías especializadas (NumPy, SciPy, Matplotlib, Pandas) que hoy constituyen el estándar de facto para el análisis de datos en física, química, biología y astronomía. Publicaciones del CERN, simulaciones del LIGO, y análisis de datos del telescopio James Webb se hacen en Python.

Python vs. MATLAB: durante años, MATLAB fue el estándar en ingeniería y física experimental. Python lo desplazó por ser gratuito, open source, y tener un ecosistema más amplio. Hoy la mayoría de los laboratorios universitarios usan Python. Si ya sabés MATLAB, la transición es directa.

// 02¿Para qué sirve en física?

Python no es un lenguaje diseñado específicamente para física, pero sus librerías lo hacen extremadamente poderoso para casi todo el flujo de trabajo experimental y teórico:

NumPy
Arrays n-dimensionales y álgebra lineal. Operaciones vectorizadas que reemplazan los loops y corren a velocidad C.
↳ vectores, matrices, FFT, álgebra lineal
SciPy
Algoritmos científicos: integración numérica, resolución de EDOs, ajuste de curvas, optimización, interpolación.
↳ odeint, curve_fit, fsolve, integrate
Matplotlib
Graficación científica publicable. Desde scatter plots hasta campos vectoriales y superficies 3D.
↳ gráficos para informes y papers
Pandas
Análisis de datos tabulares. Leer CSV de un sensor, filtrar mediciones, calcular estadísticas descriptivas.
↳ datos experimentales, CSV, Excel
SymPy
Álgebra simbólica en Python: derivar, integrar, resolver ecuaciones, simplificar expresiones, generar LaTeX.
↳ cálculo simbólico, verificar resultados
Jupyter
Entorno de notebooks interactivos: código + texto + gráficos en el mismo documento. Estándar para reproducibilidad.
↳ informes interactivos, exploración

// 03Instalación

La forma recomendada para física y ciencia de datos es instalar Anaconda o Miniconda, que incluyen Python más todas las librerías científicas preinstaladas, con un gestor de entornos virtuales incluido.

Opción A — Anaconda (recomendado para principiantes)
Descargar desde anaconda.com/download
conda create -n fisica python=3.11
conda activate fisica
conda install numpy scipy matplotlib pandas sympy jupyter

Anaconda incluye ~1500 paquetes preinstalados. Ideal si no querés lidiar con dependencias.

Opción B — Python puro + pip (más control)
Descargar desde python.org/downloads
pip install numpy scipy matplotlib pandas sympy jupyter

Más liviano. Requiere gestionar las dependencias manualmente con pip o poetry.

Opción C — Sin instalación (Google Colab)
Ir a colab.research.google.com

Python en el navegador con GPU gratis. Ideal para empezar sin instalar nada o para trabajar desde cualquier computadora.

// 04Ejemplo: ajuste de curva experimental

Este ejemplo típico de laboratorio ajusta una ley de potencia a datos experimentales, calcula las incertezas de los parámetros y grafica el resultado con barras de error, tal como aparecería en un informe de Laboratorio 1 o 2.

ejemplo_ajuste.py — ajuste de ley de potencia con incertezas
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import curve_fit

# Datos experimentales: periodo T vs longitud L de un péndulo
L = np.array([0.20, 0.35, 0.50, 0.65, 0.80, 1.00])  # metros
T = np.array([0.90, 1.19, 1.42, 1.62, 1.79, 2.01])  # segundos
dT = np.array([0.02, 0.02, 0.03, 0.03, 0.03, 0.04])  # incerteza

# Modelo teórico: T = a * L^n
def modelo(L, a, n):
    return a * L**n

# Ajuste con propagación de incertezas
popt, pcov = curve_fit(modelo, L, T, sigma=dT, absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))  # desviaciones estándar

a_fit, n_fit = popt
da, dn = perr

print(f"a = {a_fit:.3f} ± {da:.3f}")
print(f"n = {n_fit:.3f} ± {dn:.3f}")  # esperamos n ≈ 0.5

# Gráfico
L_curva = np.linspace(0.15, 1.05, 200)
fig, ax = plt.subplots(figsize=(7, 5))
ax.errorbar(L, T, yerr=dT, fmt='o', color='#ffd43b', label='Datos experimentales',
            capsize=4, ecolor='#888')
ax.plot(L_curva, modelo(L_curva, *popt), color='#5bc8f5',
        label=f'Ajuste: T = {a_fit:.3f}·L^{n_fit:.3f}')
ax.set_xlabel('Longitud L (m)')
ax.set_ylabel('Período T (s)')
ax.set_title('Péndulo simple: T vs L')
ax.legend()
plt.tight_layout()
plt.savefig('pendulo_ajuste.pdf', dpi=150)
plt.show()

El resultado imprime n = 0.500 ± 0.008, consistente con la predicción teórica T = 2π√(L/g). La función curve_fit de SciPy usa mínimos cuadrados no lineales y devuelve automáticamente la matriz de covarianza, de donde se extraen las incertezas de los parámetros.
