Análisis de Datos

ggplot2, tidyverse, ajuste de curvas e inferencia — el lenguaje estadístico que domina el análisis experimental en física y ciencias

// Rggplot2tidyverseEstadísticaRStudio

R es un lenguaje diseñado específicamente para estadística y análisis de datos. A diferencia de Python, que es un lenguaje de propósito general con bibliotecas estadísticas, R nació en 1993 directamente para estadística y todo lo demás vino después. Esto lo hace especialmente potente para el tipo de análisis que aparece en física experimental: distribuciones de probabilidad, tests estadísticos, regresión, análisis de varianza, bootstrap y visualización de datos con calidad de publicación mediante ggplot2.

En física, R aparece especialmente en análisis de datos experimentales donde la estadística es el núcleo —psicoacústica, biofísica, física médica, física de partículas— y en cualquier contexto donde la calidad visual de los gráficos importa. La gramática de gráficos de ggplot2 produce figuras que difícilmente se igualan con Matplotlib en términos de coherencia estética y facilidad de personalización.

¿Para qué sirve en física?

En física experimental, R es especialmente útil para análisis donde la estadística no es auxiliar sino central: ajuste de distribuciones a histogramas de datos, comparación de grupos con tests estadísticos, análisis de correlaciones, regresión lineal y no lineal con intervalos de confianza correctamente calculados, y generación de gráficos con múltiples paneles listos para publicación. El ecosistema tidyverse hace que la manipulación de grandes conjuntos de datos sea intuitiva y legible.

Usos típicos en física experimental: · Ajuste de distribuciones (Gaussiana, Poisson, Lorentziana) · Tests de hipótesis: t-test, chi-cuadrado, Kolmogorov-Smirnov · Regresión lineal y no lineal con intervalos de confianza · Análisis de varianza (ANOVA) para comparar configuraciones · Gráficos multipanel con ggplot2 para publicaciones · Análisis de series temporales (señales experimentales) · Bootstrap para estimación de incertezas no paramétricas

Ejemplo de uso: análisis estadístico con ggplot2

Análisis completo de datos experimentales: ajuste gaussiano a un histograma, test de normalidad y gráfico con calidad de publicación:

library(tidyverse) # Datos simulados: tiempos de caída medidos con cronómetro (en s) set.seed(42) tiempos <- rnorm(n=100, mean=1.423, sd=0.018) # --- Estadística descriptiva --- cat("Media:", mean(tiempos), "\n") cat("SD:", sd(tiempos), "\n") cat("Error estándar:", sd(tiempos)/sqrt(length(tiempos)), "\n") # --- Test de normalidad (Shapiro-Wilk) --- shapiro_test <- shapiro.test(tiempos) cat("p-valor Shapiro-Wilk:", shapiro_test$p.value, "\n") # --- Gráfico: histograma + ajuste gaussiano --- datos <- data.frame(t = tiempos) mu <- mean(tiempos) sigma <- sd(tiempos) ggplot(datos, aes(x = t)) + geom_histogram(aes(y = after_stat(density)), bins = 15, fill = "#1a6cf5", color = "white", alpha = 0.7) + stat_function(fun = dnorm, args = list(mean = mu, sd = sigma), color = "#00d4ff", linewidth = 1.2) + labs( title = "Distribución de tiempos de caída", subtitle = sprintf("μ = %.4f s, σ = %.4f s, N = %d", mu, sigma, length(tiempos)), x = "Tiempo (s)", y = "Densidad de probabilidad" ) + theme_minimal(base_size = 13) + theme(plot.title = element_text(face = "bold")) ggsave("histograma_tiempos.pdf", width = 7, height = 5)

R vs Python para estadística: Python con SciPy cubre la mayoría de los tests estadísticos que necesita un físico. La ventaja de R aparece cuando la estadística es compleja (modelos mixtos, diseños experimentales, análisis multivariado) y cuando la producción de figuras es prioritaria. ggplot2 tiene una curva de aprendizaje inicial, pero una vez dominada produce gráficos coherentes y publicables con menos código que Matplotlib. La elección práctica: si ya sabés Python, usalo. Si vas a hacer muchos análisis estadísticos complejos, vale aprender R.

R en psicoacústica y física médica

En disciplinas como la psicoacústica, la biofísica y la física médica, R es más común que Python porque el análisis estadístico es el núcleo del trabajo: comparar umbrales auditivos entre grupos, analizar señales fisiológicas, evaluar eficacia de tratamientos. Los paquetes especializados para estas áreas están más desarrollados en R que en Python.
