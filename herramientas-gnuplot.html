📈 Gnuplot:
Gráficos desde
la Terminal

La herramienta de graficación científica más veterana y portátil — integración perfecta con LaTeX, scripts reproducibles y cero dependencias

// GnuplotGraficaciónLaTeXTerminalAjuste de Curvas

Gnuplot existe desde 1986 — antes que Python, antes que R, antes que MATLAB tuviera interfaz gráfica. Y sigue activo, actualizado y siendo usado por miles de científicos. No tiene interfaz gráfica propia: se opera desde la terminal con comandos de texto, lo que lo hace ideal para automatizar la generación de gráficos en scripts, integrar directamente con LaTeX y reproducir figuras exactamente iguales en cualquier computadora sin depender de ningún lenguaje de programación.

¿Por qué usar Gnuplot en 2025 cuando existe Matplotlib? Porque Gnuplot hace una sola cosa y la hace extremadamente bien: graficar datos. No necesita Python, ni R, ni ningún ecosistema. Un archivo de datos CSV y un script de tres líneas producen un gráfico con calidad de publicación en PDF, EPS o LaTeX puro (tikz). Para un físico que trabaja en Linux con LaTeX, Gnuplot es la forma más directa de ir de "datos crudos" a "figura en el informe".

¿Para qué sirve en física?

Gnuplot es especialmente útil en tres contextos: generación rápida de gráficos desde la terminal para explorar datos, producción de figuras de alta calidad para informes LaTeX, y ajuste de curvas no lineales directamente integrado con la graficación. Su terminal epslatex produce figuras donde los labels y ecuaciones son renderizados por el propio LaTeX del documento — tipografía perfectamente consistente.

Ventajas de Gnuplot para el flujo de trabajo en física: · No requiere Python, R ni ningún lenguaje adicional · Terminal epslatex: figuras con tipografía LaTeX nativa · Ajuste de curvas integrado (fit) con incertezas · Scripts reproducibles de 5 líneas → gráfico publicable · Funciona en cualquier Linux/Mac/Windows sin instalación pesada · Lee directamente CSV, TSV, datos en columnas · Ideal para automatizar con Bash: loop → datos → gráfico

Gnuplot es a Matplotlib lo que vim es a VS Code: minimalista, rápido, opera desde la terminal, no necesita interfaz gráfica. Tiene una curva de aprendizaje inicial, pero una vez que dominás los comandos, producís gráficos más rápido que con cualquier otro método. Y como los scripts son texto puro, se versionan con Git perfectamente.

Instalación

# Linux (Ubuntu/Debian) sudo apt install gnuplot # macOS brew install gnuplot # Windows # Descargar desde http://www.gnuplot.info/download.html # Verificar instalación gnuplot --version # Iniciar la consola interactiva gnuplot # Para salir gnuplot> quit

Ejemplo de uso: datos experimentales con ajuste

Ejemplo completo: un archivo de datos de laboratorio, un script Gnuplot que hace el ajuste y el gráfico, y la salida lista para incluir en LaTeX.

# ---- Archivo de datos: pendulo.dat ---- # L(m) T(s) dT(s) 0.20 0.90 0.02 0.35 1.19 0.02 0.50 1.42 0.03 0.65 1.62 0.03 0.80 1.79 0.03 1.00 2.01 0.04
# ---- Script: grafico_pendulo.gp ---- # Gnuplot script para ajustar T = a * L^n # Modelo f(x) = a * x**n a = 2.0 # valor inicial n = 0.5 # valor inicial # Ajuste con pesos (columna 3 = incerteza) fit f(x) 'pendulo.dat' using 1:2:3 via a, n # Configuración del gráfico set terminal pdfcairo enhanced font "Helvetica,12" size 5,3.5 set output 'pendulo_ajuste.pdf' set xlabel 'Longitud L (m)' set ylabel 'Período T (s)' set title 'Péndulo simple: T vs L' set key top left set grid set style data points # Gráfico: datos con barras de error + curva ajustada plot 'pendulo.dat' using 1:2:3 with yerrorbars \ title 'Datos experimentales' pt 7 ps 1.2 lc rgb '#00d4ff', \ f(x) title sprintf("Ajuste: T = %.3f · L^{%.3f}", a, n) \ lw 2 lc rgb '#f5a623' # Para ejecutar: gnuplot grafico_pendulo.gp

Terminal epslatex: Para integración perfecta con LaTeX, la terminal set terminal epslatex genera dos archivos: un .eps con las curvas y un .tex con los labels. Al incluirlo en el documento LaTeX con \input{grafico.tex}, las etiquetas usan exactamente la misma tipografía que el resto del documento — incluyendo ecuaciones en los ejes. Es la forma más elegante de generar figuras consistentes con el texto.

Gnuplot + Bash: automatización de gráficos en laboratorio

La combinación Gnuplot + Bash es poderosa para procesar datos de laboratorio en batch. Un script Bash puede recorrer 50 archivos de datos, ejecutar Gnuplot con cada uno, y generar 50 PDFs listos para incluir en un informe — todo en un comando. Cuando tenés mediciones repetidas o barridos de parámetros, esta automatización ahorra horas de trabajo manual.
