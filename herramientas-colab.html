Colab:
Python en la Nube

Notebooks colaborativos con GPU gratis, sin configuración local — el entorno perfecto para aprender y para cómputo científico ocasional

// Google ColabJupyterPythonGPUNotebooks

Google Colab es un entorno Jupyter Notebook que corre completamente en los servidores de Google, accesible desde cualquier navegador sin instalar nada. Tiene Python preinstalado con todas las bibliotecas científicas estándar (NumPy, SciPy, Matplotlib, Pandas), y lo más valioso: acceso gratuito a GPUs (unidades de procesamiento gráfico) para cómputo intensivo. Para un estudiante de física sin acceso a hardware especializado, Colab es la forma más rápida de acceder a capacidad de cómputo real.

El modelo es simple: los notebooks se guardan en Google Drive, se comparten como cualquier documento de Google, y se ejecutan en los servidores de Google. No hay dependencias que instalar, no hay conflictos de versiones, y cualquier persona con el link puede abrir el notebook y correrlo exactamente igual. Para física computacional, esto significa que un profesor puede distribuir un notebook de simulación que todos los estudiantes pueden ejecutar instantáneamente sin problemas de configuración.

¿Para qué sirve en física?

Colab es ideal para tres escenarios en física: aprender Python sin invertir tiempo en configuración, compartir y distribuir código interactivo (notebooks que otros pueden ejecutar sin instalar nada), y acceder a GPU para simulaciones que se benefician de paralelización masiva. Para machine learning aplicado a física de partículas, astronomía o análisis de señales, la GPU gratuita de Colab puede significar la diferencia entre una simulación que tarda días y una que tarda horas.

Casos de uso en física: · Primeros pasos con Python: sin instalación, resultado inmediato · Distribución de notebooks de clase o tutoriales · Simulaciones numéricas con GPU (PyTorch, JAX, CuPy) · Análisis de datos colaborativo: compartir con el director de tesis · Notebooks interactivos con sliders y visualizaciones · Acceso a datos científicos en Google Drive desde el código

Instalación / Acceso

# No hay instalación — es una app web # Acceso: https://colab.research.google.com # Requiere: cuenta de Google (gratuita) # Para activar GPU: # Menú: Entorno de ejecución → Cambiar tipo de entorno de ejecución # → Acelerador de hardware: GPU (T4 gratuita) # Todas estas bibliotecas ya están disponibles sin pip install: import numpy as np import scipy import matplotlib.pyplot as plt import pandas as pd # Tensorflow y PyTorch también disponibles # Para instalar una biblioteca que no está: !pip install astropy # el ! ejecuta comandos de sistema

Tiempo de sesión: Colab gratuito desconecta la sesión si el notebook está inactivo por ~30 minutos, o después de ~12 horas de ejecución continua. El estado (variables, resultados) se pierde al desconectarse, pero el código del notebook se guarda siempre en Drive. Para simulaciones largas, hay que guardar resultados intermedios en Drive o en archivos. Colab Pro extiende estos límites significativamente.

Ejemplo de uso: simulación con visualización interactiva

Colab permite crear visualizaciones interactivas con widgets que el usuario puede manipular en tiempo real, sin necesidad de re-ejecutar el código. Ejemplo con una simulación de oscilador amortiguado:

import numpy as np import matplotlib.pyplot as plt from scipy.integrate import solve_ivp from ipywidgets import interact, FloatSlider def simular_oscilador(gamma=0.1, omega0=1.0, A=1.0): """Oscilador armónico amortiguado: x'' + 2γx' + ω₀²x = 0""" def ecuacion(t, y): x, v = y return [v, -2*gamma*v - omega0**2 * x] t_span = (0, 50) t_eval = np.linspace(0, 50, 1000) sol = solve_ivp(ecuacion, t_span, [A, 0], t_eval=t_eval) fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4)) # Gráfico temporal ax1.plot(sol.t, sol.y[0], color='#00d4ff') ax1.axhline(0, color='gray', linewidth=0.5) ax1.set_xlabel('Tiempo (s)') ax1.set_ylabel('Posición x(t)') ax1.set_title(f'γ={gamma:.2f}, ω₀={omega0:.1f}') # Espacio de fases ax2.plot(sol.y[0], sol.y[1], color='#f5a623', linewidth=0.8) ax2.set_xlabel('Posición x') ax2.set_ylabel('Velocidad v') ax2.set_title('Espacio de fases') plt.tight_layout() plt.show() # Widget interactivo — el usuario mueve sliders en el notebook interact(simular_oscilador, gamma=FloatSlider(min=0.01, max=2.0, step=0.01, value=0.1, description='Amortiguamiento γ'), omega0=FloatSlider(min=0.5, max=5.0, step=0.1, value=1.0, description='Frecuencia ω₀'), A=FloatSlider(min=0.1, max=3.0, step=0.1, value=1.0, description='Amplitud inicial') )

Colab como herramienta docente

Para docentes de física, Colab permite crear materiales interactivos sin infraestructura: un notebook con una simulación que los estudiantes pueden ejecutar con el link. No requiere que nadie instale Python, no hay problemas de versiones, y los estudiantes pueden modificar los parámetros directamente. El flujo es: crear el notebook en Colab → Compartir → "Cualquier persona con el link puede ver" → distribuir el link en clase.
